# 药济良仓 YAOJI LIANGCANG

中药包装物流一体化服务平台 · 一物一码区块链溯源系统

> 贵州医科大学 · 本草智运队 · 创新创意组

## 在线地址

https://blucatmiao.github.io/yaoji-liangcang/

## 项目简介

面向中小药企与种植户，构建 **分类包装 + 专业仓储 + 温控物流 + 区块链溯源** 四位一体服务体系，
解决中药材流通环节"包装粗放、仓储不合规、无温控、溯源缺失"四大痛点。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 分类包装 | 根及根茎 / 花叶全草 / 果实种子 / 皮类 / 贵细 / 普通 六类定制方案 |
| 专业仓储 | GSP 合规仓，温湿度分区管控 |
| 温控物流 | 全程冷链，温湿度每 5 分钟自动上报并上链 |
| 区块链溯源 | 药济链 YJL-Chain 联盟链存证，一物一码不可篡改 |

## 在线演示

- 首页二维码：**手机扫码直达**该批次溯源页
- 溯源查询：输入溯源码或扫描包装码，查看全链路履历、区块链存证与温湿度曲线
- 在线赋码：输入批次号即可生成可扫码访问的二维码并下载 PNG

示例溯源码：

```
YJLC-2026-TM-0001  贵州大方天麻（贵细类）
YJLC-2026-TS-0002  贵州施秉太子参（根茎类）
YJLC-2026-SH-0003  贵州兴义铁皮石斛（贵细类）
```

## 关键成效

- 流通损耗率：10% → 2% 以下
- 综合成本：下降 20%~30%
- 已合作验证：贵州优胜美达物流有限公司

## 技术说明

单文件静态站点（`index.html`，HTML + CSS + 原生 JS，零依赖），
二维码由内置 qrcode-generator 在浏览器端按当前网址动态生成，
更换域名后无需重新制码。
